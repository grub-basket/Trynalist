# 0.80.1

Everything since 0.80.0: a stylesheet clean-up for the community-store review, and the source code now lives in this repository. Requires Obsidian 1.11.4 or later.

## 0.80.1 — store review fixes
- The stylesheet no longer uses `!important`, `:has()` or MathJax tag selectors, all of which the store's CSS lint warns about. Hidden settings rows and filtered pane rows are hidden by the plugin directly; the mobile visibility popover is laid out by the stylesheet alone; display maths in notes keeps its left alignment through selector specificity.
- Global search: the "only the innermost hovered row lights up" behaviour is now set by the plugin as you move the mouse, instead of by a `:has()` rule. Same look.
- Links use a dotted bottom border instead of a dotted text underline (solid on hover).
- The result grid uses `gap` instead of `column-gap`.

## Repository
- `src/`, `package.json`, `package-lock.json`, `tsconfig.json` and `esbuild.config.mjs` are now included, so the plugin can be built from source (`npm ci && npm run build`) and reviewed by the community store. `main.js` is still committed and is what BRAT installs.
