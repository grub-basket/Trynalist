# 0.34.0

## Copy, cut and delete act on the current item

With the cursor in an item and nothing highlighted, `Mod+C` and `Mod+X` now act
on that item and everything under it — the same rule code editors use, and what
makes those shortcuts useful without selecting first. Highlighted text still
gets the ordinary copy, and a multi-item selection still wins over both.

`Mod+Shift+K` deletes the current item (or the selection) with its children, and
it is undoable.

**Copy with creation timestamps** is a new command and menu entry. The stamp
sits after the bullet and before the text, so what you paste is still a valid
outline.

## Duplicate this document

Obsidian's own "duplicate this file" produces a broken copy, because a Trynalist
document is a folder plus a manifest and the built-in copies only the manifest.
**Duplicate this document** copies the whole thing — every item included.

## Text size, independent of Obsidian's zoom

A slider in settings scales Trynalist documents only, so an outline can be
denser or larger than the notes beside it. Individual documents can override it,
with commands to nudge a document's size or return it to the global setting.

Note that this is separate from the magnifier beside a bullet, which zooms into
an item rather than changing the text size.
