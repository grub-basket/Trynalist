# 0.64.5

- **Links and embeds to a Canvas, a Base, or another Trynalist document render as
  a typed chip** — its own icon and the file name, opening the file on click —
  instead of bare underlined text or a generic attachment chip. Ordinary notes
  stay plain links. A chip is used rather than a live inline preview: a full
  Canvas or Base embedded inside an outline bullet would be heavy and crowd the
  outline, and these surfaces are better opened in their own pane.
