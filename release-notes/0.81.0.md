# 0.81.0

Everything since 0.80.1: the source code passes the community-store review lint, and the keyboard shortcuts moved to where the store allows them. Requires Obsidian 1.11.4 or later.

## Keyboard shortcuts
- The store forbids plugins from shipping default hotkeys, so Trynalist's commands no longer carry them in Obsidian's hotkey settings. The same chords still work inside a document (Mod+] / Mod+[ zoom, Mod+Up / Mod+Down move, Mod+. fold, Mod+Shift+C checkbox, Mod+Z / Mod+Shift+Z / Mod+Y structural undo and redo, Mod+Shift+K delete, Mod+Shift+M move to, Alt+Enter line break, and the rest): they are now handled by the document view itself, only while the keyboard is in a document.
- New setting, "Built-in shortcuts" (on by default). Turn it off to bind your own in Obsidian's hotkey settings.

## Source review fixes (no behaviour change)
- Typing: Obsidian's `moment` is now typed (the `moment` type package is a dev dependency), frontmatter reads are narrowed instead of left as `any`, and zip helpers no longer need type assertions.
- Promise handling: click and modal callbacks that returned promises are wrapped so rejections still surface; a few unhandled promises are now awaited or explicitly ignored.
- Regular expressions: redundant escapes removed; filename sanitisers build their control-character ranges at runtime.
- `this` aliasing removed from nine helpers; a `var` became a hoisted `let`; the deprecated `activeLeaf` and `setDynamicTooltip` calls are gone; `caretPositionFromPoint` is tried before the deprecated `caretRangeFromPoint`.
- `builtin-modules` replaced by Node's own `builtinModules` list in the build config.

## Not changed
- `execCommand("insertText")` in the two paste handlers and the `keyCode === 229` composition check stay: no replacement keeps native undo or the Safari composition signal.
- `setWarning` stays on four buttons: its replacement needs Obsidian 1.13.
- The settings tab still uses `display()`; the declarative settings API is a later migration.

## Repository
- `main.js` in this repository is now the clean `npm ci && npm run build` output, and the release workflow builds it from source before uploading, so the release asset and a build from source match.
