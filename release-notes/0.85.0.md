# 0.85.0

Everything since 0.84.0: a round of fixes and sizing changes for phones. Requires Obsidian 1.11.4 or later. Desktop is unchanged.

## Highlights

- **One tap to edit.** Tapping a row on iOS now puts the caret in it on the first tap instead of the second.
- **Side panels stay put.** Swiping along the keyboard toolbar, or dragging to select text in the row being edited, no longer opens a side panel.
- **Toolbar sits on the keyboard.** The gap above the keyboard is gone.
- **Dismiss keyboard button.** New toolbar button, third by default. A toolbar that has already been customised keeps its layout; add the button from the gear.
- **Larger touch targets.** On mobile, text, row icons, spacing and the top buttons are scaled up together. The Density setting still applies.
- **The current line stays visible.** The outline scrolls to keep the line being typed on above the toolbar.
- **Dialogs clear the keyboard.** New document, Bookmark this view and the other Trynalist dialogs sit in the space above the keyboard.
- **Open trash has its own icon,** so it no longer looks like Delete.

## All changes

### 0.85.0

- One tap focuses a row. iOS treats a tap as a hover when hovering would reveal content, and every row revealed its menu icon on hover. Hover reveals for the row menu, zoom action, bullet icon and panel row actions are now desktop-only.
- On mobile the row menu and zoom action follow focus, and panel row actions are always visible. The zoom action takes no taps until its row is focused, so a tap left of a bullet cannot zoom by accident. The bullet tooltip is not used on mobile.
- A plain row is no longer rebuilt when it gains focus, which avoids disturbing the caret during a tap.
- The keyboard toolbar carries Obsidian's `data-ignore-swipe` opt-out, and a row's text or note carries it while focused. Swiping elsewhere on the outline still opens the side panels.
- The toolbar's bottom padding is the home-indicator inset minus `--keyboard-height`, so it disappears while the keyboard is up.
- New "Dismiss keyboard" toolbar action (`keyboard-off` icon). It is left out of the Mod+K command bar.
- A dismissed keyboard stays dismissed: the remembered focus is cleared, so folding, zooming or a sync does not refocus the row.
- "Open trash" uses the `archive-restore` icon.
- Trynalist dialogs extend a new `TrynalistModal` base class. On phones they are centred in the space above the keyboard, and a long dialog scrolls inside that space. An earlier version in this release padded the sheet instead (superseded by the centring).
- The outline scrolls to keep a collapsed caret between the sticky header and the toolbar, on selection changes and viewport resizes. Fields taller than about four lines are skipped when the caret has no measurable position, so a long note cannot be thrown off screen.
- Touch sizing on mobile: text 1.15×, row controls 26px with hit areas the full height of the row, taller rows with the spacing on the text so the strip between rows is tappable, indent and guide line recalculated, and header buttons 36px.
- Vertical sizing on mobile hangs off one value tied to the Density setting: compact, default and comfortable all stay aligned.
- The sticky search bar is offset below the taller mobile header.
- Version bump to 0.85.0.
