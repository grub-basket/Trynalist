# 0.77.1

Everything since 0.65.2: a full release review, sync safety, big-document speed, a reworked Dynalist update, mirror fixes, and many smaller corrections. Requires Obsidian 1.11.4 or later.

## 0.77.1 — lint hygiene
- The popout-window observer is typed without `globalThis`.
- The deep-link warning reads "that link does not point at an outline document".
- Developer notes updated (not part of the plugin).

## 0.77.0 — large documents open fast
- Documents with 1,200 or more visible items draw 400 at a time and fill in the rest as you scroll, when the cursor moves into it, or when you jump to an item. A full redraw of a 4,000-item document drops from about half a second to under a tenth.
- After a redraw the view keeps the same item at the top, instead of a pixel offset.

## 0.76.6 — mirrors
- Mirror and portal bodies honour Hide completed, and show numbering and checklist boxes inherited from the source document.
- Switching a mirror between mirror and portal, and collapsing a mirror, can be undone.
- Duplicate document points the copy's own mirrors at the copy's items.

## 0.76.5 — moves keep their Dynalist link
- Moving items to another document, or turning an item into a document, keeps each item's creation time and Dynalist id down the whole subtree, so the next Dynalist update does not re-create them.

## 0.76.4 — speed
- Import and update pace their requests from the start of each read.
- MathJax is no longer loaded at startup.
- Search no longer adds a keyboard listener on every redraw.
- Notes rendered in search results are released when the results change.
- Images load lazily.
- The agenda recompute is shared between callers, ignores items overdue by more than 180 days, and prunes old reminder state.
- The document scan reads manifests in parallel.
- Collapse all and Expand to level write their files in parallel and show progress on big documents.
- Saving an item's text writes its file once instead of twice.
- Imports write item files 16 at a time.
- Capture to inbox writes one file when the inbox is closed, and goes through the open tab (undoable, no reload) when it is open.
- Drag and drop works out the drop position once per drag and finds the gap by binary search.
- Ordinary typing no longer forces a layout on every key.
- Drag-selecting repaints only the rows whose selection changed.
- Arrow keys reuse a cached list of visible items.
- Flat and Article views show items in pages with a "Show more" button; the Flat view's ancestor trail is plain text.
- Tags, attachments, `[[` suggestions, search across documents, import comparison and the link audit share one cache of loaded documents, cleared when those documents change.
- Drag and drag-select caches are dropped when the outline redraws.

## 0.76.3 — editing and document management
- An item deleted from another view of the same document is not written into the trash.
- An item created under a parent that no longer exists goes to the top level.
- Folding and renumbering no longer mark items as edited.
- Undo and redo survive a failed file write.
- Deleting the item you are zoomed into zooms out first.
- "Delete checked items" from the palette or toolbar covers the whole document.
- A refused drop no longer uses up an undo step.
- Ticking several selected recurring items rolls each forward.
- Undo history is smaller on phones and is dropped when a file closes.
- Blank rows are saved when the app quits or a phone puts it in the background.
- Upload from the mobile toolbar always leaves the link it reports.
- Renaming or moving a document keeps its settings, Recents entry and bookmarks.
- Duplicate document copies its attachments too.
- Archiving from the combined panel refreshes the Files and Archive panes.
- The Tags pane picks up new tags by itself.
- The root-folder setting applies when you leave the field or press Enter, with folder suggestions.
- When two item files share an id, the newer one is shown and a notice says so.
- The integrity report names both duplicate files and which one is shown, and skips Trynalist's own internal folders.
- README: Mod+↑/↓ and the heading shortcut described as they actually behave.

## 0.76.2 — safety
- Link chips open on a primary click only, and ask before handing a file to another app.
- Deep links open only Trynalist documents inside the root folder.
- Obsidian's file-open hook is restored safely and keeps the caller's `active` flag.
- Importing a key from the keychain shows which secret it will use and asks first.
- Link patterns stay fast on text dense with brackets.
- One very long line can no longer blank the outline.
- The Attachments list shows only real attachments, and missing bare file links.
- Pasted and dropped files get a safe file name.
- The folder converter only treats a folder as Stashpad when its notes look like Stashpad notes.
- Stashpad → Trynalist conversion reads a note's own frontmatter even before Obsidian has indexed it.
- Conversion removes a Stashpad sidecar file only once its backup exists.
- Trynalist → Stashpad conversion keeps fractional sibling order.

## 0.76.1 — import, formats and backup
- OPML import decodes entities once, and a bad character reference no longer aborts it.
- Indented-text import nests by the raw indent width.
- Loading a document reads fresh frontmatter for files written a moment ago.
- A byte-order mark no longer costs an item its frontmatter.
- A carriage return inside item text stays inside the item.
- A due date that is not text no longer silences every reminder.
- A document with an empty title takes its folder's name.
- File names made from titles are length-capped and never a reserved Windows device name.
- A new document never collides with a folder whose name differs only in case.
- Items added in Dynalist land where Dynalist has them.
- Import resume only offers imports that are really stalled on this device.
- Backup restore checks file sizes, follows Obsidian's path rules and never half-restores silently.

## 0.76.0 — performance
- Inserting an item no longer rebuilds the whole index.
- Moving an item among its siblings rewrites only that item.
- A batch delete makes one trash entry and one rebuild.
- In-document search draws at most 300 matches until you ask for all.
- Typing a new bullet no longer rescans the vault behind the panel.
- The Tags pane with no tags stops rescanning the vault on every refresh.
- The import comparison draws in slices.
- The mind map draws at most about 1,500 boxes and says when it is capped.

## 0.75.0 — Dynalist update
- Update merges three ways: local edits are kept (and reported as conflicts when Dynalist changed the same item), local deletions stay deleted, and documents unchanged in Dynalist are skipped.

## 0.74.3 — undo and outside changes
- Undo can no longer roll back a change made on another device or empty a document.

## 0.74.2
- Minimum Obsidian version raised to 1.11.4.
- Pasted attachments get a space before and after them.

## 0.74.1
- A row left showing raw markup after a partial redraw is rendered again.

## 0.74.0 — mirrors
- Paste mirror and Paste portal are back, so mirrors can be created again.
- Mirrors follow their source through renames, mirror-of-mirror chains and live edits; a broken reference shows a clear row.
- Editing next to mirrors no longer hides or loses items, and every delete warns about mirrors pointing at what is being deleted.
- Duplicating, copying and exporting keep mirrors.
- Mirrors stay read-only and are left out of views that cannot show them.
- The link audit reads mirror references the same way the mirror resolver does.
- Developer notes updated (not part of the plugin).

## 0.73.1
- Type checks work in popout windows.
- The tag pattern avoids lookbehind, so the plugin loads on iOS before 16.4.
- Store-lint hygiene: no inline styles, console output, stray disables or casts.

## 0.73.0 — copy and paste
- Copy and paste inside Trynalist keep colour, heading, notes and line breaks.

## 0.72.0 — security
- Resuming an import rebuilds every path from validated input.
- Notes in documents shared with you render restricted (no scripts, no remote images) unless you trust the document from its title menu.

## 0.71.0 — sync robustness
- A parent missing at load time no longer gets detached for good.
- Typing into an item deleted on another device recreates it instead of failing.
- Notes save after a short pause, and unsaved typing is written on quit and when the app goes to the background.
- A cross-document move reloads the destination if it is open.

## 0.70.0 — trash, undo and insert-as-item
- Undoing a delete takes the item files back out of the trash.
- Trash restore finds the document by id, never duplicates ids, and reloads the document it restored into.
- Pasted attachments are embedded with a link built by Obsidian.
- "Insert a document as an item" archives the original instead of trashing it.
- New item file names leave out dates, parentheses and `!`.

## 0.69.0 — correctness
- Shift+Enter opens the item's own note, not a child's.
- A recurring item's next occurrence and cross-document moves keep the checkbox.
- Snoozing from the agenda fires again when the snooze runs out.
- "Add / edit date" edits the existing date instead of adding a second one.
- `has:checkbox` matches items with their own unticked checkbox.
- Exports carry checkboxes correctly; OPML import keeps unticked boxes.
- Inline `$maths$`, `*italic*` and `~sub~` need flanking characters, so prices and spaced asterisks stay plain text.
- Dates and tags of linked items no longer leak into the item linking to them.
- Markdown-style links to vault files open.
- Indent, Unindent and Move commands leave the zoomed-in item where it is.
- Manifest writes patch the file instead of overwriting it with a stale copy.
- Exports name their file from a cleaned-up title.
- Date-only items are due that day rather than overdue from midnight.

## 0.68.1
- Popout windows: caret, selection, popovers and styling use the popout's own window.

## 0.68.0
- Links in rendered notes open again (internal links, tags, web links).
- Rendered notes are cached, so full redraws stop re-parsing them.
- The `[[` popover stops rescanning the vault after every typing pause.
- Search across documents reads each document once per session and stops stale runs.
- Drag-select repaints the selection on mouse-up instead of redrawing everything.

## 0.67.0 — incremental repaint
- The caret is placed by walking the row's text, which fixes errors on rows showing rendered markup.
- Edits repaint only what they touched instead of redrawing the whole document.

## 0.66.1 — sync-safe documents and settings
- Open documents pick up changes made on other devices instead of reverting them.
- Settings are merged three ways with the synced settings file instead of overwriting it.
- Undo keeps Dynalist ids on items it brings back.

## 0.66.0 — release review fixes and the sync safety net
- An empty item line is kept on load, so a note-only item stays note-only.
- Enter-split and multi-line paste keep line breaks inside an item.
- Enter at the start of an item opens an empty row above it.
- Editing a hidden note no longer erases it.
- Note saves trim only the end, keeping a first-line indent.
- "Notes: 1st line" no longer flattens a note when it is edited.
- Removing a chip or unlinking an attachment no longer flattens notes.
- Unlinking an attachment reloads open tabs on the documents it changed.
- Paste and templates keep notes and checkboxes.
- Import and update no longer silence reminders due later in the week.
- Outdenting a direct child of the zoomed item no longer moves it out of view.
- Keys that belong to an IME composition are ignored.
- The folder converter closes open tabs on the folder before converting it.
- The integrity check no longer reports false orphans on a cold cache, and asks before reattaching.
- Sync safety net: automatic local snapshots of settings (on change) and the outline (daily), per device, with restore commands; 30 days kept, never fewer than 5.
- Developer notes updated (not part of the plugin).
