# 0.65.1

Two small quality-of-life changes.

- **Import notices stay until you close them.** The progress, completion and
  failure notices for a Dynalist import or update no longer vanish on a stray
  click — Obsidian hides a notice on any click anywhere on it, which could
  dismiss a multi-line summary before you had read it, or the progress notice
  while the import was still running. Only the notice's own buttons close it:
  Cancel, Open report, and a new Dismiss.
- **"Open documents in a new tab" now applies everywhere.** Opening a
  Trynalist document from the file explorer, the quick switcher or a wikilink
  in an ordinary note used to replace whatever you were reading; it now adds a
  tab, like the panels and the document opener already did. A document that
  is already open is brought forward rather than opened twice, and closing
  the new tab returns you to the one it came from. Turning the setting off
  restores Obsidian's default behaviour on every route.
