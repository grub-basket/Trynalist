# 0.64.0

Import from Dynalist. This release adds a full read-only importer for the Dynalist
outliner, the tools to keep an import current, and a handful of fixes.

## Import from Dynalist

Bring an entire Dynalist account into Trynalist over Dynalist's official API —
read-only, so it can never change anything in your Dynalist. Paste your API token
(from dynalist.io/developer) when prompted, or in settings.

- **Whole account in one run.** The folder tree is recreated and every document
  imported, each run into its own dated folder so repeated imports never mix
  together.
- **Token stored in your keychain.** The token is kept in Obsidian's own secret
  store (the OS keychain), never in plain text in the vault. A settings control
  can adopt a token already stored under a "dynalist" key, and a note reminds you
  to revoke the token when you're done.
- **Faithful metadata.** Items keep their checkbox state (including a
  checkbox-without-tick), colours, headings, notes, collapse state, and their
  Dynalist created/modified timestamps. Every item also records where it came
  from and the source document's permission level, and any field without a
  first-class column is preserved verbatim — so nothing Dynalist sends is dropped.
- **Shared documents.** Documents shared with you are imported by default; a
  setting limits the import to documents you own.
- **Raw source archive.** By default each run also saves the exact API responses
  in a `_source` folder — an immutable snapshot to rebuild from later.
- **Robust for large accounts.** Reads are rate-limited to stay within Dynalist's
  limits, each request times out rather than hanging, and a document that is slow
  on the first pass is set aside and revisited with a longer budget instead of
  failing.
- **Cancel and resume.** An import can be cancelled from its progress notice or a
  command, keeping everything already imported. If the app quits mid-import, the
  next launch offers to resume where it left off.
- **Quiet during import.** Reminder pop-ups are paused while importing so a
  calendar of dated items doesn't flood the screen; imported due items are shown
  in the agenda instead.

## Keeping an import current

- **Update an existing import** re-fetches the account and folds changes into an
  existing run folder: changed items are updated in place, new items added, and
  items removed in Dynalist are MARKED (not deleted), reversibly. Item and
  document identities are matched on their stable Dynalist ids, so links and
  mirrors survive. Re-running also backfills any newer metadata onto notes
  imported by an earlier build, while keeping their timestamps.
- **Compare two imports** shows what changed between two runs — added, removed,
  changed (with which fields) and unchanged — with filters to hide the unchanged
  or the added/removed.

## Other tools

- **Back up the whole collection** to a single lossless `.zip`, and **restore**
  it into a fresh folder — an exact, portable copy of everything.
- **Audit links** finds broken links across all documents: wikilinks and embeds
  that resolve to nothing, and mirrors whose source is gone, grouped by document.

## Import a single file

Alongside the API importer, single documents can still be imported from an OPML,
Dynalist JSON, or indented-text file, or by pasting an outline.

## Fixes

- **The document toolbar no longer lets text peek — or be edited — in a sliver
  above it** when scrolling. The sticky breadcrumb/toolbar now sits flush against
  Obsidian's header.
