# 0.33.0

## Splitting an item works reliably

Pressing Enter in the middle of an item could leave the pushed half on BOTH
rows — the truncated text reached the model, but a save fired by the redraw
could write the original text straight back over it. The same fault that
affected `Alt+Enter`, fixed the same way.

## Backspace at the start of an empty indented row outdents it

Previously only rows with text did. Enter-then-Backspace now walks a new row
back out a level; once it reaches the top level, Backspace merges as before.

## Selection is visible on the row you are in

A selected row that still held the cursor was painted with the focus highlight,
which beat the selection colour — so the row you were on looked unselected even
though it was selected and was being copied. The selection now wins.

## Undo leaves you somewhere

Undoing could remove the row holding the cursor, leaving no cursor and no
selection. Undo and redo now put focus on a row that exists.

## Searching is no longer a dead end

Every search view has three new actions: widen to a search across all
documents, show the current document in the panel, and bookmark the search
itself so a query you keep re-running becomes one click.

## Creating things

**New document** and **New folder** now let you choose the folder they go into,
defaulting to wherever you clicked. Both dialogs are half their previous width,
sized in a way that grows with Obsidian's text size and zoom.
