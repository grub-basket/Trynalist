# 0.64.3

Performance for large accounts.

## Faster imports

Importing a big Dynalist account is dramatically faster. Each imported item is now
written to disk in a single operation, with its complete frontmatter composed up
front — where it previously took several disk operations per item plus a rebuild
of the whole document each time. Combined with the panel fix in 0.64.2 (panels no
longer re-scan the vault on every file an import writes), a very large account
that took hours now completes in a fraction of the time.

Imported files are identical to before — the same frontmatter, structure, and
metadata — just written more efficiently.
