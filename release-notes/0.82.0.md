# 0.82.0

Everything since 0.81.0: a shortcut reference in settings. Requires Obsidian 1.11.4 or later.

## Settings
- New "Shortcut reference" below the "Built-in shortcuts" toggle. It lists every built-in chord with the command it runs, formatted for your platform (⌘⇧⌥ on macOS, Ctrl+Shift+Alt elsewhere).
- Use it to copy the scheme into Obsidian's hotkey settings if you turn built-in shortcuts off, or want one of them to work outside a document. Search the hotkey settings for this plugin's name.
- The list is generated from the same chords the document view registers, so it always matches what actually fires.
