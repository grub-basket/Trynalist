# 0.36.0

## Back and forward inside a document

Obsidian's own history knows which file a pane is showing, but nothing about
where you are *within* a document — so zooming three levels in and pressing Back
either did nothing or left the document entirely.

There are now back and forward buttons in the breadcrumb bar that track zooming
and view changes. A zoom target that has since been deleted returns you to the
document root rather than stranding the view.

## Escape closes any search

Escape only worked when the cursor was in the search box. A search started from
the tags pane leaves focus in that pane, so it could only be dismissed with the
"Done" button. Escape now works from anywhere in the document.

## Move to… searches other documents

The picker only ever searched the open document, so moving something *elsewhere*
had no answer. A search with no local matches now widens to every other
document, showing which document each result belongs to.

Moving across documents asks first and explains the one thing worth knowing:
undo covers the document you moved *from*, not the one you moved *to*.

## `Mod+D`

Deletes the current item, or the selection, with children — alongside
`Mod+Shift+K`. Both leave highlighted text alone.
