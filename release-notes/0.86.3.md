# 0.86.3

Everything since 0.86.2: an index of the file and folder names Trynalist shortened, so you can match each short name with its full name outside Obsidian too. Requires Obsidian 1.11.4 or later.

## Highlights

- **Shortened names, listed.** Since 0.86.2, Trynalist shortens names that would make a path too long for Windows. A new file, `_Shortened names.md` at the top of your Trynalist folder, lists every shortened file or folder by its full path, next to the full name it would have had. In File Explorer, OneDrive or a zip, where only the short names show, that's how you tell them apart.
- **Kept up to date for you.** Rows follow renames and moves, are copied when you duplicate a document, and go when the file or folder is deleted.
- **Rebuild command.** "Rebuild the shortened-names index" rescans the vault. It drops rows for paths that are gone, re-adds the document folders and items it can work out again, and keeps everything else.

## All changes

### 0.86.3

- New file `_Shortened names.md` at the top of the Trynalist folder: a table with the full vault path of each shortened name and the full name it would have had. It's created the first time a name is shortened. Rows are added for item files in deep folders, document folders, new plain folders, split duplicates, trash groups and pasted attachments.
- Rows follow renames and moves, including moving a folder that holds shortened files. Duplicating a document copies the rows for its attachments. Deleting a file or folder removes its rows. Renaming a document to a title that fits removes only that document's own row; its items keep theirs.
- New command "Rebuild the shortened-names index". It removes rows whose file or folder no longer exists, and adds document folders (from the title in their `.trynalist` file) and item files whose current text still gives the name they were shortened from. Rows it can't work out again are kept: plain folders, attachments, and items edited since.
- Names in the table are written as code, so underscores, asterisks, brackets and backticks show as typed. Edits made to the file by hand are overwritten.
- A note of your own that already has the name `_Shortened names.md` in the Trynalist folder, empty or not, is never written. The rebuild command says so instead.
- Changes are collected and written about two seconds later, when the app quits, when a phone puts it in the background, and for a few seconds while the plugin is turned off. Deleting or moving a large folder doesn't slow the app down.
