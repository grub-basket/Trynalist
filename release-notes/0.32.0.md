# 0.32.0

## Undo remembers what you typed

Undo previously covered structural changes only — moves, indents, deletes — so
typing relied on the editor's own per-element history, which is lost the moment
a row redraws and cannot cross rows at all.

A snapshot is now taken at the start of a typing burst, so a paragraph of
typing collapses into one undo step. A pause of about a second, or moving to
another item, begins the next step. `Mod+Y` redoes, alongside `Mod+Shift+Z`.

## Backspace at the start of an indented item outdents it

As in Dynalist. An empty indented row still merges away, which is how you
delete a stray row.

## Flat view shows indentation levels

Each row carries an `L1` / `L2` / `L3` badge. Flattening otherwise throws away
the one thing the outline made obvious.

## Adding things

The `+` in the documents panel now offers **New document**, **New folder**, and
**Import from OPML…**, each with its own icon. The import opens your system file
picker and reports anything the parser had to guess at rather than silently
dropping it.

## Tags

Right-clicking a tag was being treated as a left click, so a tag could only do
one thing. It now opens a menu — search the open document, search every
document, copy the tag, and a count of the documents it appears in. A plain
click now searches the **open document** first; widening to the whole vault is
a deliberate second step.

## Fixes

- Created and modified times in the bullet tooltip line up now, right-aligned
  and monospaced.
- Shift+↑/↓ at the very top or bottom of a document makes sure that row is
  itself selected rather than doing nothing.
