# 0.29.2

## Dynalist's keyboard shortcuts are the defaults again

`Mod+A` (select one level up), `Mod+F` (search this document), `Mod+↑/↓` (move
an item) and `Mod+]` / `Mod+[` (zoom in and out) ship bound again. They were
removed in 0.28.2 while a shortcut conflict with another plugin was being
tracked down; that conflict turned out to be unrelated.

These are safe to claim because every Trynalist command fires only while the
keyboard is genuinely inside a Trynalist document. With a sidebar, a search box
or another plugin's pane focused, the same chord does whatever it normally
would. Clear any of them in Obsidian's hotkey settings if you would rather keep
the chord for something else.
