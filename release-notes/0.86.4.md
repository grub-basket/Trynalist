# 0.86.4

Everything since 0.86.3: a fix for losing the last words you typed. Requires Obsidian 1.11.4 or later.

## Highlights

- **No more lost typing when you close a tab.** Trynalist saves a row about half a second after your last keystroke, and a note about a second and a half after. If you closed the tab, switched it to another file, or turned Trynalist off within that time, what you'd just typed was lost. It's now saved.

## All changes

### 0.86.4

- Text typed into a row less than 0.6 seconds, or into a note less than 1.5 seconds, before closing its tab, switching the tab to another file or document, or turning Trynalist off is now saved. Obsidian removes a tab's contents before the tab's last save runs, so that save found nothing. Now each keystroke also keeps a copy of the text, and the last save uses it when the row or note is gone.
- A note closed like that keeps its line breaks. Read from a closed tab, a note lost them.
- An open tab saves from what's on screen exactly as before. The copy is dropped whenever the row or note is saved, split or joined, so it can't bring back older text.
