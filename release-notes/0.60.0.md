# 0.60.0

A large release. Search is rebuilt, the item menu is customisable, documents
carry their own visibility settings, and there is a mobile toolbar.

## Search

Three scopes, switchable from inside a search rather than only exitable: **in
doc**, **flat**, and **all documents**. The query survives the switch. In-doc
search filters the outline in place and keeps the hierarchy, so a result still
reads as part of the outline it came from; flat is a plain list, and the only
mode a sort applies to.

Global search happens inside the document view instead of a separate tab, which
is what lets Escape, Back and the header controls keep working. Results group by
document, each hit drawn with its ancestors, matched words marked. Hovering a
row lights it and everything under it; clicking zooms to that item. Results
update as you type, debounced.

Flat results sort by title, date, checked state, edited or created, in either
direction, plus "reverse current order".

The last query is remembered across sessions and an X clears it. Scope chips
carry their keyboard shortcuts. A Back control sits first in the search bar in
every mode.

The operator reference is now a dialog listing all 23 operators, grouped, with a
section on writing dates.

### Search operators

- `is:checklist` added.
- The leading minus for past dates now parses: `edited:-1w` means the last week,
  `1w` means the week ahead. Previously any query using the documented minus
  form matched nothing.
- `until:` and `within:` ran in the wrong direction — `until:2w` meant two weeks
  ago rather than two weeks ahead, and `within:1w` silently included the past
  week as well. Both follow the sign now.

### Search shortcuts

`Mod+F` opens or focuses the search. `Mod+G` and `Mod+Shift+G` walk the matches
and wrap. `Mod+O` opens the document jump; `Mod+Shift+F` searches everywhere.
`Shift+Enter` goes flat, `Mod+Enter` goes global. Each is claimed only while the
keyboard is in a Trynalist row, so nothing else loses the chord.

## The item menu

Rebuilt against Dynalist's, at 32 entries: collapse, collapse all, expand all,
expand to level, collapse all siblings, add note, indent, unindent, move to,
show all references, export, delete checked items, and the existing entries.

"Expand to level" offers only the levels a document actually has. Sort gained
its missing directions. "Show all references" reports both mirrors and Obsidian
backlinks.

The menu is **customisable** — reorder or hide any entry from Settings →
Behaviour. Hidden entries stay reachable from the action bar.

**Templates** exist: save an item and its subtree, then insert it under any
other item. Templates are stored as an indented outline, so they can be written
by hand or pasted in.

## Mod+K action bar

A searchable list of every item action, acting on the focused row. A zap button
in the header opens the same thing. The toolbar, the action bar and the
customiser all read one list, so an action cannot appear in one and be missing
from another.

## Per-document visibility

An eye in the header opens per-document settings for checked items, notes,
layout and text direction. Each row has a "Global" option that reports what it
currently resolves to. A document follows the global setting until given its own
answer, so changing a global still moves everything untouched.

Text direction applies the `dir` attribute, so caret movement and Home/End
behave correctly in right-to-left text, and gained a global setting.

## Mobile

A keyboard toolbar with seventeen actions, in Dynalist's order, scrolling
horizontally. It is customisable — reorder, hide, or add the four extras.

Buttons keep the caret and keyboard in place when tapped. The bar is positioned
against the visual viewport so it sits above the on-screen keyboard.

The visibility menu is a tighter stack on a phone.

## Links and deep links

Wiki links are written using Obsidian's own link generator, so they follow the
"New link format" preference instead of always being absolute paths — which is
also what lets Obsidian's rename-updater keep them working. Autocomplete now
offers every vault file, not only Trynalist items.

`obsidian://trynalist?…` deep links address an item, or a zoomed view of one.
"Copy deep link" and "Copy deep link (zoomed in)" are on the item menu, and the
breadcrumb has one too.

## Tabs

Opening a document adds a tab rather than replacing what you were reading
(Settings → Behaviour). Closing that tab returns to the tab it was opened from,
or the one to its left.

## Outline

Clicking the vertical indentation line folds its parent, and `Mod+Up` /
`Mod+Down` fold and unfold — both borrowed from the Outliner plugin by vslinko.
The line is drawn under the parent's bullet rather than at the indent's edge.

The zoom control on a row becomes a zoom-out when you are standing on that item.

Colour swatches carry the letters A–F, in the theme's text colour.

Date and file chips carry a leading icon — a calendar, an image, or a paperclip.

## Reminders

Quiet hours gained **quiet days**: whole days of the week with no reminder
toasts, Monday first. The agenda still lists them.

## Fixes

- The reminder toast was the one notification that never used the plugin's own
  toast layout — no accent, no action row.
- Dates with a zero-padded hour never rendered. `!(2026-08-20 09:30)` showed as
  literal text while an afternoon time worked. The date picker writes padded
  hours, so a morning time picked from the picker could not be read back.
- Pasting an outline flattened everything below one level. The indent width was
  judged per line, so one paste could apply two conventions at once. Copying
  from Trynalist and pasting back into it was affected from 0.38.0 onward.
- Emphasis marks doubled against their own closer: typing `**` produced `***`.
  Typing a symmetric mark inside its own pair now grows both sides.
- The mind map appeared not to work when a search was open — it stored the mode
  and kept drawing the outline. Switching to it closes the search.
- Escape did not leave a search opened from the tags pane.
- Select-all did not progress beyond the first press, and dead-ended in a note.
  It now climbs from either starting point.
- Edit note created the note field without focusing it.
- The zoom control stayed visible on the focused row.
- Colour swatches had no accessible name, and hovering one erased the colour it
  existed to show.
- Notice action buttons had no focus ring.

## Notes

- Layout has a global default, so it behaves like the other visibility settings.
- Documents opened from the panel land on the item you last had focused.
- The panel's ribbon button closes the panel when it is already showing.
