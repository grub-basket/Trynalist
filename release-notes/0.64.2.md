# 0.64.2

Fixes and follow-ups for the Dynalist import.

## Fixes

- **Imported documents no longer open blank.** Right after an import writes a
  document, its files aren't in Obsidian's metadata cache yet — loading read
  frontmatter only from that cache, so every item looked absent and the document
  opened empty. Loading now falls back to parsing each file's own frontmatter, so
  it doesn't depend on cache timing. A document that genuinely fails to load now
  shows an error with a Retry button instead of a blank pane.
- **"File already exists" failures during an update are gone.** Re-adding an item
  whose file the cache hadn't reported could collide with the file still on disk
  and fail the whole document; the writer now adopts the existing file instead of
  colliding.
- **Panels stop thrashing during an import.** The Documents panel and side panes
  no longer re-scan the whole folder on every file the import writes (the source
  of the console "setTimeout handler took Nms" warnings) — they refresh once when
  the import finishes.

## Reports and retries

- **An import or update now writes a report and opens it in a tab** — which
  documents changed, what was updated vs. metadata-backfilled, what failed and
  why, and what was skipped. The one-line notice couldn't hold that.
- **Metadata backfills are now counted.** Re-running an update over documents
  imported by an earlier build fills in the newer metadata on every item; that is
  reported as "metadata-backfilled" rather than hiding inside "unchanged".
- **Retry failed documents in an import…** re-fetches only the documents that
  failed last time (recorded per run), instead of the whole account.

## Polish

- The import/update progress notification was redesigned: a clear heading, the
  current document, a progress bar, and a tidy Cancel.
