# 0.64.6

Targeted updates from Dynalist.

- **Update only the documents you choose.** "Update selected documents from
  Dynalist…" lists your account's documents in a searchable checkbox picker
  (filter by title or folder, select-all-of-the-filter), then re-fetches only
  those — for running over a handful (e.g. the ones a rate limit left unfinished)
  instead of the whole account. It costs a single file/list call before you pick.
- **The report of a selected run lists every chosen document with its status** —
  Updated, Backfilled, Added (new document), Items marked removed, Unchanged, or
  Failed with a reason — so a targeted run answers exactly what happened to each
  one, not just the ones that moved. A whole-account update keeps its concise
  changed-only view.
