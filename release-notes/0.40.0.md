# 0.40.0

## Appearance

- **The bullet sits on the first line** of a multi-line item instead of halfway
  down it.
- **Zooming in** now makes the item you zoomed to read as a heading, with its
  children indented beneath it. They used to line up with it, which suggested
  they were siblings.
- Callouts inside a note no longer carry page-sized spacing.

## Editing

- **Enter on an empty indented item outdents it** rather than adding another
  empty sibling — the usual way back out of a nested list. There is a setting
  for it under Behaviour.
- **Pasting a single line strips its list marker**, so `- foo` no longer arrives
  with a second bullet in the text.
- **Pasting an outline is two undo steps**: undo once to get the original
  markers back, undo again to remove the paste.
- **Shift+clicking inside the item you are editing** selects text, as in any
  editor. It used to select the whole item, which made selecting across the
  lines of a multi-line item impossible.
- **Copies leave empty items out** by default, keeping their children at the
  right depth. Configurable.
- **Clean up empty items** is a new command. It works from the leaves up, so a
  chain of blanks collapses without orphaning anything, and it tells you exactly
  how many will go — an empty item that still holds real content is kept.

## Getting around

- **Every pane has a filter box** that narrows as you type; Escape clears it.
- **Breadcrumbs have a context menu**: zoom here, open in a new tab, open to the
  side, or copy the item's text.
- **Heading and colour are rows of choices** in the item menu rather than
  submenus.
- Opening a document returns you to the item you were last on.
