# 0.42.0

## Typing punctuation

- A **third identical opening bracket stays literal**, so `[[[` gives you three
  brackets rather than a nest of pairs. `[[` is already a wikilink, so a longer
  run is deliberate.
- **Typing a closing bracket where one already sits steps past it** instead of
  adding a second.

Smart quotes and dash substitution are deliberately absent. Trynalist stores
plain Markdown, and quietly rewriting characters you typed changes your data
rather than just your typing.

## What renders where

An item's own text and its note use different renderers, and that is on purpose:

- **A note** gets Obsidian's full Markdown — blocks, tables, callouts, fenced
  code, embeds.
- **An item's text** gets inline formatting only: bold, italic, highlight,
  strikethrough, code, maths, links, tags, dates, sub- and superscript.

Block constructs in an item's text stay as you typed them. An item is one line,
and a blockquote or a table is multi-line by definition — `Shift+Enter` puts you
in the note, which is where those belong.
