# 0.64.4

Import/update reporting refinements.

- **The completion notice has an "Open report" button.** The import/update report
  no longer opens itself and steals focus when a long run finishes — it's written
  every time, and the notice opens it on demand.
- **"Documents changed" is now an honest fraction.** It reads "X of Y", counting
  only the documents that actually changed — an update that re-touches every
  document without changing most of them no longer reports them all as "changed".
- **The report lists newly added documents by name**, rather than leaving you to
  infer them from the table.
