# 0.38.0

## Copy, cut and delete shortcuts work

`Mod+C` and `Mod+X` did nothing while text was highlighted, and `Mod+D` did
nothing at all. Two causes: Obsidian already uses `Mod+D` for one of its own
editor commands, so ours was contested; and a plugin command that steps aside
still leaves the shortcut claimed, so registering `Mod+C` risked shadowing the
ordinary copy.

All three are handled directly in the outline now. With text highlighted, copy
and cut leave it alone so the ordinary copy happens; with nothing highlighted,
they act on the item and its children. Delete works either way.

## Copied outlines keep their indentation

Copies used tab characters, which many editors and chat boxes discard — so an
outline pasted elsewhere arrived flat. Copies now use **two spaces per level**
by default, configurable in settings (four spaces or tabs). Pasting back into
Trynalist understands all of them.

## Deleting is fast again

Every delete was checking all of your documents for mirrors pointing at what you
were removing. In a vault with many documents that took seconds. The check is
cached and skipped entirely when no mirrors exist — deleting an item now takes
about a tenth of a second.

## The breadcrumb bar stays put

It sticks to the top as you scroll, so the back and forward buttons, the
document title and the view switcher stay reachable in a long document.
