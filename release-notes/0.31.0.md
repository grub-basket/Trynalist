# 0.31.0

## Copying items works

Selecting rows and pressing `Mod+C` did nothing. Selecting rows clears the
browser's own text selection, and no copy event is fired when nothing is
natively selected — so the clipboard code, which hung entirely off that event,
was never reached.

Copy and cut are now proper commands on `Mod+C` and `Mod+X`, and they appear in
an item's menu as **Copy (with children)** and **Cut (with children)**. They
only claim the shortcut while items are block-selected, so copying ordinary
selected text is untouched.

The copied text is an indented outline — children, notes and checkbox state
included — which pastes back into Trynalist at whatever depth you drop it, and
into any plain-text editor as a readable list.

## Undo and redo have shortcuts

The commands existed but had no keys bound, so `Mod+Z` did nothing to structure
and undo appeared to be missing entirely.

`Mod+Z` and `Mod+Shift+Z` now undo and redo structural changes — moves,
indents, deletes, splits, line breaks. They only claim the shortcut when there
is something on the stack, so ordinary typing still gets the editor's own undo
as before.
