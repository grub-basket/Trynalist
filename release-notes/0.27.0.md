# 0.27.0 — first public beta

The first build published for BRAT testing. Everything below is in this
release; there is no earlier public version to diff against, so this is a
complete inventory rather than a changelog.

**This is beta software.** It writes real files into your vault. Keep backups
of any vault you try it in.

## Storage

- Documents live under a root folder (`Trynalist/` by default), one subfolder
  per document, identified by a `<Doc>.trynalist` manifest.
- Every outline line is one Markdown file. Its frontmatter carries `id`,
  `parent`, a fractional `order` among siblings, the authored `indent`, a
  normalised `depth` (distance from the document root, so an outline written
  with irregular indentation still reads correctly), `created`/`modified`, and
  item state.
- The file body is the item on its first line and the note underneath it.
  Line breaks inside an item are escaped, so a file is always one physical line
  per item.
- Blank rows live in memory until they have content, so drafting a list does
  not write a file per keystroke.
- Deleted items go to the vault trash. Nothing is hard-deleted.

## Editing

- Split and merge on Enter and Backspace, indent and outdent on Tab, move on
  Alt+Arrow, and structural undo/redo as commands (so they never take over the
  rows' own text undo).
- Multi-select with Shift+Arrow, Shift+click, Mod+click, click-and-drag across
  rows, and a Mod+A ladder that widens one step at a time: the line's text, the
  item, its siblings, then upward. Selecting a parent selects its children.
- Bulk indent, move, delete, and check across a selection.
- Drag and drop with a drop guide, including horizontal travel to change depth.
  Hold Option (or Ctrl) to copy the subtree instead of moving it.
- Copy a selection as an indented outline that pastes back at any depth, in
  Trynalist or in any plain-text editor.
- Auto-pairing for brackets and formatting marks, with selection wrapping and
  type-over. Obsidian's own `autoPairBrackets`, `autoPairMarkdown` and
  `smartIndentList` settings are honoured, so pairing is configured once for
  the whole app.
- Enter inside a note continues the list it is in: bullets continue, an empty
  item exits, ordered lists renumber, task items continue unchecked, and
  blockquotes continue.
- Pasted images and files are written into the document's own attachments
  folder and linked. Pasted rich text is flattened, and pasted multi-line text
  becomes rows with its indentation preserved.

## Views

- **Outline** — the default, with zoom into any item and a breadcrumb trail.
  The item you zoom into stays editable at the top.
- **Flat** — every item at one level.
- **Article** — prose-style, for reading.
- **Mind map** — a read-only one-sided bracket over the document, with pan,
  zoom, fit-to-view, and a breadcrumb that fills in when a node is clicked.
  Box heights are measured rather than estimated, so notes and wrapped lines
  do not cause overlaps.

## Formatting

- Inline bold, italic, strikethrough, highlight, inline code, LaTeX, tags,
  links, wikilinks, and image embeds.
- Six heading levels, per-item colours, checkboxes, and numbered lists.
- Notes render through Obsidian's own Markdown renderer: syntax-highlighted
  fenced code with a copy button and its language named, tables, callouts,
  footnotes, math, task lists, and embeds.
- Items show raw source while focused and render when not, which is what
  Dynalist documented for itself.

## Dates and reminders

- Inline dates with an optional time, recurrence, and a due-date agenda split
  into overdue, today, and coming up.
- Configurable date format, 12- or 24-hour clock, AM/PM, and first day of the
  week (Sunday, Monday, or Saturday).
- In-app reminders with a lead time, snooze, and quiet hours.

## Navigation

- A combined documents panel with collapsible sections and counts, plus
  separate panes for files, bookmarks, tags, recent, agenda, and archived.
- Search within a document and across all documents, with operators.
- A document jump list, bookmarks, and an item finder.
- An attachments manager that lists every attachment, finds unused and missing
  ones, previews them, and jumps to the item using each.

## Mirrors and portals

Show a subtree from elsewhere — including from another document — as a window.
A mirror shows the source item and everything under it; a portal shows only its
children. They are one node type with a mode, so both behave consistently.

Read-only in this release: editing through a mirror means writing into another
document, and undo would have to span both.

## Import and export

- Import from Dynalist OPML, Dynalist JSON, and indented text.
- Export to `<Doc>.trynalist.zip`, holding a readable nested-bullet Markdown
  outline plus lossless node metadata, and to OPML and plain text.
- Convert a folder between Trynalist and Stashpad layouts in either direction,
  preserving sibling order, attachments, and subfolders.

## Known limitations

- Mirrors are read-only, and a mirror inside a mirrored subtree is not expanded.
- Dynalist's themes are not included; Trynalist uses your Obsidian theme.
- No sharing, publishing, or account features, by design.
